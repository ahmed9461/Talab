# Talab Design System

The canonical visual source of truth is now `design-system/talab/MASTER.md` following the UI/UX Pro Max master/override pattern.

Talab is an Arabic-first customer service portal with a calm premium SaaS direction. Priorities are accessibility, touch safety, mobile-first responsive layout, explicit feedback, and status communication using icon + text rather than color alone.

Do not introduce a new palette, font, radius scale, navigation pattern, or animation language without updating the master design system first.
