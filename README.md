# Talab — طلب

بوابة عملاء خفيفة لطلب الخدمات ومتابعة حالة الطلب واستقبال الإشعارات.

## v0.1
المرحلة الأولى تتضمن:
- واجهة عربية RTL وMobile-first.
- إنشاء حساب بالاسم واسم المستخدم وكلمة المرور ورقم الجوال.
- اختيار نوع الخدمة من قائمة.
- إظهار وصف إضافي تلقائيًا عند اختيار «أخرى».
- الموافقة على شروط الخدمة.
- حالة نجاح أولية بعد إرسال النموذج.
- Design System موثق لتثبيت أسلوب الواجهة عند التوسع.

## التشغيل
```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

## UI/UX
يعتمد المشروع على مبادئ UI/UX Pro Max:
https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

راجع `docs/DESIGN_SYSTEM.md` و`AGENTS.md` قبل تعديل الواجهات.

## القادم
Backend API + PostgreSQL + نظام تسجيل الدخول والحالات + بوت إدارة تيليجرام + مركز الإشعارات والمرفقات.
